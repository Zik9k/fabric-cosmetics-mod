# Fabric Cosmetics Mod

Custom cosmetics (hats, capes, wings) for Minecraft Fabric 1.21.4.

## Status
- [x] Project scaffold
- [ ] Hat render layer
- [ ] Cape support
- [ ] Wings
- [ ] Config / GUI

## Setup
1. Install JDK 21
2. Install Fabric Loom / use the Fabric template
3. Clone this repo
4. Run `./gradlew runClient`
